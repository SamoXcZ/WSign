Features

Everything a signer needs, in one app.

On-device signing

Sign any .ipa with your own .p12 certificate and provisioning profile, right on your iPhone. No computer, no cable.

One-tap install

Signed apps install straight onto this device from the Sign tab.

Built-in file manager

Import files of any size, multi-GB IPAs included. Unzip, compress, rename, duplicate, share, and edit text and plist files.

Pack as IPA

Unzip an app, change what you need, and pack the Payload folder back into an installable IPA.

Tweak injection

Inject .dylib, .deb and .framework files. A built-in CydiaSubstrate replacement lets most tweaks load without a jailbreak.

Customize

Keep the app's own bundle ID, name and version, or change them. Extra options: file sharing, removing extensions or the Watch app, and minimum iOS version.

Certificates

Keep several certificates, pick a default, and see when each one expires.

Install

Get WSign on your device.

WSign is shared as an unsigned IPA. Download it, sign it with your own certificate, and install it on your iPhone or iPad.

Unsigned IPA

There is no store listing or source to add. Grab the file and sign it yourself.

Install IPA
  1. Download the IPA to your device.
  2. Sign it with your own .p12 certificate and provisioning profile, using the signer you already have.
  3. Install the signed app. If iOS asks, trust the profile in Settings → General → VPN & Device Management, then open WSign.

Looking for a newer version? Contact the developer.

Using WSign

Four taps from IPA to installed.

Settings → Add Certificate

Add your certificate

Choose your .p12, enter its password, then pick the matching provisioning profile.

Files tab

Import an app

Bring in any .ipa from Files, Safari or another app. Size doesn't matter.

Tap the .ipa → Import to Sign

Send it to Sign

The app opens in the Sign tab with its name, bundle ID and version filled in.

Sign tab

Check, sign, install

Review the details, add tweaks if you want, then sign and install in one go.
